# 1on1管理シート 理事会リマインドメール自動送信スクリプト

## 概要

このGoogle Apps Scriptは、Googleスプレッドシートで管理されている「1on1リスト」に基づき、マンションの理事会開催日を基準として、関係者にリマインドメールとフォローアップメールを自動で送信するためのものです。

メールは理事会開催の**3日前**と**2日後**に、それぞれ異なる内容で送信されます。

## 主な機能

- **理事会前のリマインドメール送信**：理事会開催日のN日前（デフォルトは3日前）に、EV充電設備に関する議題をリマインドするメールを送信します。
- **理事会後のフォローアップメール送信**：理事会開催日のN日後（デフォルトは2日後）に、理事会での反応や今後の進め方について確認するメールを送信します。
- **柔軟なCC設定**：案件ごとの営業担当者や工事会社担当者をCCに自動で追加します。
- **送信制御**：特定の案件に対して、手動でメールの自動送信を無効にするフラグを設定できます。
- **重複送信防止**：一度送信したメールは、送信日をシートに記録することで、重複して送信されるのを防ぎます。

## 準備と設定方法

### 1. スプレッドシートの準備

このスクリプトを動作させるには、特定の名と構造を持つ4つのシートが必要です。

#### ① メインシート (シート名: `1on1`)

メール送信のトリガーとなる情報を管理します。以下の列（ヘッダー）を1行目に設定してください。

| 列ヘッダー名 | 説明 |
| :--- | :--- |
| `マンション名` | **必須**。メールの件名や本文に記載されます。 |
| `次の理事会日` | **必須**。メール送信日の基準となる日付を入力します。 |
| `フロント担当者` | **必須**。メールの宛先（To）となる担当者名を入力します。 |
| `理事会前メール送信日` | **必須**。スクリプトが自動で入力します。**空の列として準備してください。** |
| `理事会後メール送信日` | **必須**。スクリプトが自動で入力します。**空の列として準備してください。** |
| `自動送信無効` | **任意**。この列に `TRUE` またはチェックを入れると、その行のメールは送信されません。 |
| `CC担当1` | **任意**。CCに追加する営業担当者名を入力します。 |
| `CC担当2` | **任意**。CCに追加する営業担当者名を入力します。 |
| `工事会社` | **任意**。CCに追加する工事会社名を入力します。 |
| `支店・部署` | **任意**。メールの署名部分に記載されます。 |

#### ② フロント担当者シート (シート名: `フロント担当者`)

メールの宛先（To）となる担当者のメールアドレスを管理します。

| 列ヘッダー名 | 説明 |
| :--- | :--- |
| `フロント担当者名` | **必須**。`1on1`シートの担当者名と完全に一致させてください。 |
| `メールアドレス` | **必須**。送信先のメールアドレス。 |

#### ③ 営業担当者マップシート (シート名: `営業担当者マップ`)

メールのCCに追加する営業担当者のメールアドレスを管理します。

| 列ヘッダー名 | 説明 |
| :--- | :--- |
| `営業担当者名` | **必須**。`1on1`シートの`CC担当`列と完全に一致させてください。 |
| `メールアドレス` | **必須**。CCに追加するメールアドレス。 |

#### ④ 工事会社マップシート (シート名: `工事会社マップ`)

メールのCCに追加する工事会社のメールアドレスを管理します。

| 列ヘッダー名 | 説明 |
| :--- | :--- |
| `工事会社名` | **必須**。`1on1`シートの`工事会社`列と完全に一致させてください。 |
| `メールアドレス` | **必須**。CCに追加するメールアドレス。 |

### 2. スクリプトの初期設定

スクリプトエディタを開き、`自動メール送信用.gs` ファイルの上部にある設定項目を必要に応じて変更します。

```javascript
// --- 設定項目 ---
const SHEET_NAME = '1on1'; // メインで操作するシート名
const CONTACT_SHEET_NAME = 'フロント担当者'; // 担当者名とメールアドレスが記載されたシート名
const CC_MAP_SHEET_NAME = '営業担当者マップ'; // CC担当者名とメールアドレスが記載されたシート名
const CONSTRUCTION_MAP_SHEET_NAME = '工事会社マップ'; // 工事会社名とメールアドレスが記載されたシート名
const COMMON_CC_EMAIL = 'sales@ubiden.com'; // 固定で追加する共通CCアドレス
const REMINDER_DAYS_BEFORE = 3; // 理事会日の何日前に「前」メールを送信するか
const REMINDER_DAYS_AFTER = 2;  // 理事会日の何日後に「後」メールを送信するか
// --- 設定項目ここまで ---
```

### 3. トリガーの設定

メールを毎日自動で送信するために、トリガー（定時実行の設定）を設定します。

1. スクリプトエディタの上部メニューから `実行` > `関数を実行` > `createDailyTrigger` を選択します。
2. 初回実行時には、Googleから承認を求めるプロンプトが表示されます。内容を確認し、承認してください。
3. 「毎日午前9時〜10時にメールを自動送信する設定が完了しました。」というダイアログが表示されれば、設定は完了です。

これにより、毎日午前9時から10時の間に `sendScheduledEmails` 関数が自動的に実行され、条件に合致するメールが送信されます。

## 注意事項

- 各シートのヘッダー名（1行目のテキスト）は、スクリプトが列を正しく認識するために重要です。変更しないでください。
- マップ用の各シート（フロント担当者、営業担当者マップ、工事会社マップ）に記載する担当者名や会社名は、`1on1`シートに記載する名前と完全に一致している必要があります。（スペースの有無などにご注意ください）
- スクリプトがエラーで停止した場合、ログ（`表示` > `ログ`）で原因を確認できます。
